# 🤖 GenAI Chat Application

A simple AI-powered chatbot built using **Python, Streamlit, and Google's Gemini API**.

The application provides a clean chat interface where users can enter prompts and receive AI-generated responses from Google's Gemini model.

## 🚀 Live Demo

👉 [Try the GenAI Chat Application](https://genai-chat-application-xavcsxtiu3mxxxp8zqfncw.streamlit.app/)

## ✨ Features

- 💬 Interactive chatbot interface
- 🤖 AI-generated responses using Google Gemini
- 🧠 Maintains conversation history during the session
- 🌐 Deployed using Streamlit Community Cloud
- 🔐 API key stored securely using Streamlit Secrets
- 🖥️ Simple and beginner-friendly UI

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Google Gemini API**
- **google-genai**
- **python-dotenv**
- **Git & GitHub**
- **Streamlit Community Cloud**
